Налаштування

Порожнє поле — значення за замовчуванням, показане в ньому сірим. Для Ollama це справжні значення моделі. Top-k і розмір контексту можна задати лише через рідний API Ollama: в OpenAI-сумісному API таких параметрів немає. У рідному API Ollama low/medium/high означають просто «з міркуванням».

Навантаження

Назва запуску потрапляє в таблицю й CSV, щоб порівнювати запуски, наприклад до й після оптимізації. Наведіть курсор на заголовок колонки таблиці, щоб побачити, що вона означає. Браузер тримає не більше ~6 одночасних зʼєднань з одним сервером, тож рівні понад 6 клієнтів тут не покажуть справжнього навантаження — для них використовуйте bench.py.

Назва запуску Клієнтів Помилок Тривалість, с Токенів на запит TTFT p50, с TTFT p95, с Швидкість для користувача, tokens/s Throughput, tokens/s

Модель міркувала перед відповіддю: TTFT включає час міркування, а tokens/s завищений. Оберіть «без міркування».
