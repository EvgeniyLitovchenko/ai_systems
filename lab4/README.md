# Лабораторна 4 — Картки з конспекту

Локальна генерація пар «запитання–відповідь» із навчальних текстів, Qwen3 4B через Ollama. Інтерфейс — проста вебсторінка, поруч вебbench із методичних матеріалів.

- [Ноутбук із демо, відповідями на 20 запитань і звітом](local_models_demo.ipynb).
- [Текстова копія звіту](REPORT.md).
- [Вимірювання оригінальним bench.py](bench_results.csv).
- [Код та інструкція запуску](app/README.md).
- [Демонстрація](demo/README.md).

Швидкий запуск із цієї теки після налаштування моделей за інструкцією:

```powershell
python app/app.py
```

Відкрити [картки](http://localhost:8000/) або [bench](http://localhost:8000/bench.html).

Додаткові JSON у `results/` містять фактичні відповіді моделей, PPL-експерименти, перевірку якості й походження скриптів із методичних.
Середовища Python та ваги моделей не включено. Збережені виходи початкового демо відокремлено від нових локальних запусків.
Усе підготовлено локально; публікація та подання через форму не виконувалися.
