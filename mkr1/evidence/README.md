# Докази й походження даних

- `usage/recipe_borscht.txt`, `recipe_cabbage.txt`, `recipe_pizza.txt` — справжні рецепти, які користувач надав у чаті як страви для використання в застосунку. Формат скопійованого тексту збережений.
- `usage/manual_baseline.json` — повідомлений користувачем виміряний час 2 хв 52 с для ручного об’єднання **перших двох** рецептів, без пошуку цін. Також зафіксовано 120 с пошуку АТБ і 140 с «Сільпо», разом 432 с. Перша спроба із застосунком — 52 с із негативним відгуком щодо цін; повторний час після доопрацювання не домислюється.
- `usage/events.jsonl` — фактичні інтерактивні дії в застосунку під час перевірки й демонстрації на цих рецептах. Вони підтверджують роботу прототипу, але не видаються за історію самостійного користування протягом кількох днів або реальні покупки.
- `usage/measurements.jsonl`, якщо створено, — фактичні введені користувачем вимірювання однакового завдання до/після.
- `technical/` — автоматичні перевірки, реальні відповіді локальної моделі та каталогів магазинів, скриншоти інтерфейсу. Старі помилки в журналі розробки не приховуються; фінальні зведення мають окремі назви.

Ціни — знімок на зазначений у JSON час, для конкретних магазинів Житомира. Вони не гарантують майбутню ціну чи наявність. AI-оцінки кількостей окремо позначаються та не вважаються вихідною розміткою рецептів.

Фінальна перевірка після відгуку: `technical/improved_basket_summary.json` і `improved_user_session.json`. Початковий результат користувача окремо збережено в `usage/first_user_session.json`. `technical/unit_tests.txt` містить результат 25 тестів. Відео — огляд реальних кадрів із субтитрами, не безперервний запис проходження.
